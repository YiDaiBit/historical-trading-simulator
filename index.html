玩法说明

一个"不知道未来"的历史行情交易练习场。

画面分三栏

  • ① 最左 · 标的：搜索并点选要交易的资产。
  • ② 中间 · 我的持仓：上方是账户概况（权益、可用资金、多空市值、盈亏）， 下方是全部持仓，每条腿都能单独「平」。
  • ③ 最右 · K线图 + 买卖：上面看图（可切资金曲线 / 成交记录 / 绩效统计）， 下面就是该标的的持仓和下单区。
  • 两条竖向分隔条可拖动调栏宽（双击复原）；图表和下单区之间那条横向分隔条 可拖动调高度（双击复原）。

核心规则

  • 数据是真实历史日线（开高低收），覆盖全球主要股指、大宗商品、加密资产。覆盖范围与口径见行情数据集说明。
  • 你只能看到当前日期及之前的走势，右边（未来）永远是黑的。
  • 默认 10 秒真实时间 = 1 个交易日；顶栏可随时切换 1 小时 / 10 分钟 / 1 分钟 / 3 秒 / 极速，也能手动点 ⏭ 单步。
  • 日期下方有倒计时，会实时显示离下一个交易日还有多久——它在走，只是可能很慢。
  • 周末和休市日不在时间轴上——每推进一格，就是下一个真实交易日。
  • 双向持仓：同一资产可以同时持有多头和空头两笔独立仓位， 互不抵消（对冲模式）。下单区四个按钮分别是 开多 开空 平多 平空。
  • 下单按金额计算，自动折算数量（支持小数）。成交价 = 当日收盘价，另收手续费。
  • 开空占用 50% 保证金，按空头市值冻结；可用资金 = 现金 − 空头保证金。
  • 总权益跌破 0 即爆仓，本局结束。权益 = 现金 + 多头市值 − 空头市值。

操作提示

  • ①点标的 → ③看图 → ③下单，持仓在②里。
  • 联动定位：点①里的某个资产，②持仓栏会自动滚动到它的持仓并高亮 （金色竖条 + 闪烁）；反过来点②里的某个持仓，①标的栏也会跳过去。 当前选中的资产在持仓栏里会常亮一条金色标记，一眼可辨。
  • 想看得更宽敞：拖两侧竖向分隔条调宽；中间栏右上角 ⇔ 一键加宽； 总权益旁的 ⌃ 收起账户明细，把高度全留给持仓。
  • 持仓栏右上角 ▤ 切换紧凑模式，每条腿压成一行，同样高度多看约一倍。
  • 减仓（不是全平）：持仓行上的 平 按钮会弹出一个菜单， 可以选 10% 25% 50% 75% 全部， 只平掉这条腿的一部分，剩下的继续持有。开仓均价保持不变。
  • 想同时做多做空：先点开多买一笔，再点开空卖一笔，两笔会并列显示。
  • K线上方的区间按钮（近2月 / 近半年 / 近1年 / 近3年 / 近5年 / 全部） 按真实日历天数取数；图表右下角会显示当前实际显示的起止日期。
  • 鼠标悬停在图上可看当天开高低收与涨跌幅，当天有成交会一并列出。
  • K线上的买卖点：▲ 实心红 = 开多、 △ 空心红 = 平空、 ▼ 实心绿 = 开空、 ▽ 空心绿 = 平多。 买点画在 K 线下方，卖点画在上方；三角形大小代表成交金额大小。 图表工具条的 买卖点 可以开关。
  • "资金曲线"页可对比等权买入持有基准，看自己有没有跑赢躺平。
  • "持仓分析"页：资产配置占比（含现金，合计 100%）、空头敞口、类别分布、 盈亏贡献排行、集中度（最大单一 / Top3 / HHI），以及全部持仓的明细表。
  • "投资组合"页：把若干资产配成一组并设定目标权重，然后一键对整个组合加仓 / 分档减仓 / 清仓，按权重自动分配到每个成分。组合保存在本地，跨局沿用。
  • 进度会自动存在浏览器里，关掉网页再打开可以"继续上局"。 有存档时弹窗只显示「继续上局」和一份设置摘要——时间流速、手续费率、初始资金、 做空开关都是上次的值，不用重填；想改这些参数就点「丢弃存档，重新开一局」。
  • 投资组合：在"投资组合"页把若干资产配成一组、设好目标权重，之后 「一键加仓 / 建仓」会按权重把金额分摊到每个成分；「减仓 25% / 50% / 全部清仓」 按各成分的持仓比例整组减仓。组合存在本地，跨局沿用。
  • 你的设置会被完整保留：时间流速、下单方向、K线区间、均线开关、图表选项、各栏宽度与折叠状态，更新版本后依旧沿用上局的选择。

为什么要这样设计

  • 看历史图表时人人都是股神，因为你知道后面发生了什么。这个游戏把"后面"删掉， 逼你在信息不完整的条件下做决策——这才是交易的真实处境。
